Two stamps on every skill your agents run.

Publishers sign their skill catalogs with a key that never leaves their machine. Axela verifies each publication and countersigns it, so your machines accept a catalog only when both signatures check out — a stolen publisher key alone publishes nothing, and neither does a compromised notary.

Open the console

Publish from CI, no secrets

A GitHub Actions job authenticates with the OIDC identity GitHub mints for it. Axela checks the repository claim against your registration and countersigns — nothing to store, nothing to leak.

Verify offline

Machines pin both public keys and check every skill before every session, from the catalog already on disk. The network is for refreshing, never for deciding.

See what happened

When a machine quarantines a tampered skill and restores the signed version, it files a signed report. The console shows the fleet's incidents — and can do nothing else, because no signing key lives here.

Organisations are registered by the operator; there is no self-service signup yet. The API lives under /v1/.
