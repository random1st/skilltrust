# Product vocabulary

The terms below cover the approved connection and reporting changes. Existing
catalog, attestation, subscription, and event names keep their current meanings.

## Index

- **Check result** `CheckResult` kind:value
- **Connection** `Connection` kind:value
- **Enrollment** `Enrollment` kind:process
- **Machine** `Machine` kind:entity
- **Receipt** `Receipt` kind:value

## Terms

### Check result
- **Definition**: A signed account of one computer's latest completed or partial verification of an explicit scope, including coverage and catalog freshness.

### Connection
- **Definition**: Public organisation configuration returned after browser approval of a computer; it does not imply a successful check.

### Enrollment
- **Definition**: The browser-approved association of a proven machine key with an organisation member and a scoped report credential.

### Machine
- **Definition**: A computer identified by its signing key; a display name is not its identity.

### Receipt
- **Definition**: An immutable server acknowledgement of accepted signed evidence, with its signer and acceptance time.
